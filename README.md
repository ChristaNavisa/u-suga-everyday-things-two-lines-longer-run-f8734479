Two lines explaining a toaster to a 10-year-old: the toaster as a tiny elevator for bread, then an honest line about what that elevator picture maps (the trip down and up, the browning) and what it leaves out (the heat, the smell, and that bread never chooses to ride).

Run with `node main.ts`; it writes the two-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
